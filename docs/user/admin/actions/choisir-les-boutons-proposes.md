**Administration → Actions.** Chaque action a sa carte, avec deux interrupteurs :

| Interrupteur | Commande les boutons de… |
|---|---|
| **Après chaque réunion** | L'onglet **Transcription** : envoyer, entreposer, télécharger la transcription |
| **Après chaque résumé** | L'onglet **Résumé** : envoyer, entreposer, télécharger le résumé en PDF |

## Étapes

1. Dans les cartes **Envoyer par mail**, **Entreposer** et **Télécharger**, activez ou désactivez les
   interrupteurs.
2. Regardez **Ce que verront vos utilisateurs**, en tête de l'onglet : la barre de boutons telle
   qu'elle apparaîtra, garde-fous compris. « Aucun bouton ne sera affiché. » si tout est fermé.
3. Cliquez **Enregistrer**.

## Ce qu'il faut savoir

- **Entreposer** n'apparaît qu'avec un fournisseur : voir [Choisir le compte relié](choisir-le-compte-relie.md).
- **Envoyer par mail** apparaît chez un utilisateur s'il existe un relais d'envoi sur le serveur, **ou**
  s'il a relié son compte. Le message « Aucun relais SMTP n'est configuré sur ce serveur : le bouton
  « Envoyer par mail » n'apparaîtra pas. » ne vaut que pour les utilisateurs sans compte relié.
- **Fermer une action** ne supprime aucun réglage des utilisateurs : leurs destinataires et leurs
  dossiers restent enregistrés, et reprennent si vous rouvrez.
- Les utilisateurs voient le changement au prochain chargement de myBrief.
