**Administration → IA**, carte **Modèle de rédaction du compte rendu**.

## Les modèles proposés

| Modèle | Pour |
|---|---|
| **gpt-5.6-sol** | Le plus capable, le raisonnement le plus profond. Le plus cher |
| **gpt-5.4** | **Recommandé** : le meilleur rapport qualité-prix pour un compte rendu. Le modèle par défaut |
| **gpt-5.4-mini** | Le plus économique et le plus rapide : un compte rendu plus ramassé, moins de nuances |

## Étapes

1. Choisissez le modèle dans **Modèle utilisé pour les comptes rendus**.
2. Cliquez **Tester l'accès au modèle** : « Modèle accessible ». Le test vérifie que votre organisation a
   accès au modèle ; il ne juge pas la qualité, et ne coûte qu'une fraction de centime.
3. Cliquez **Enregistrer**, en bas de l'onglet.

## Résultat

Le modèle rédige les comptes rendus suivants, pour tous les comptes. Les comptes rendus déjà produits ne
changent pas. Les titres des réunions et la détection d'actions gardent leur propre modèle.

## Ce qu'il faut savoir

- **Un modèle imposé par la configuration du serveur**, hors de la liste, est signalé. En choisir un dans
  la liste le remplace, sans retour possible depuis cet écran.
- Pour juger la qualité, générez un même compte rendu avec deux modèles : **Nouveau résumé** sur une
  réunion de test, entre deux changements.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| « OpenAI a refusé ce modèle de rédaction — votre organisation n'y a probablement pas accès. » | Choisissez un autre modèle, ou demandez l'accès chez OpenAI. |
