Les six templates fournis — Standard, Réunion de décision, Entretien RH, Brainstorming, Planification,
Rétrospective — se modifient comme les autres. Votre version remplace l'originale **pour tous les
comptes**.

## Étapes

1. **Administration → Templates**, cliquez un template portant le badge **défaut**.
2. Lisez la note : sauvegarder remplace la version d'origine pour tous les comptes.
3. Modifiez les **Directives à l'IA** et la **Mise en forme du résumé**. Ce que l'éditeur affiche est
   la version utilisée aujourd'hui.
4. Cliquez **Sauvegarder**.

## Résultat

Le badge devient **défaut modifié**. Au prochain chargement de myBrief, tous les comptes utilisent votre
version.

## Ce qu'il faut savoir

- **Enregistrer sans rien modifier ne change pas le rendu** : l'éditeur montre la version qui
  s'applique.
- **Les titres de votre mise en forme ne se traduisent pas.** Dans sa version d'origine, un template
  fourni a des titres anglais quand l'interface est en anglais ; adapté, il garde les vôtres dans les
  deux langues.
- **Un template fourni ne se supprime pas** : vous pouvez seulement l'adapter ou le rétablir.
- **Le Pagimètre de Standard** (1 page d'origine) se règle dans la section **Pagimètre** : autre
  position par défaut, ou désactivé. Un Standard adapté **avant** l'arrivée du Pagimètre ne l'a pas :
  activez-le dans cette section, ou rétablissez le défaut.
- **Les points de départ de « Mes templates »** restent les versions d'origine.

## Revenir à la version d'origine

Cliquez **Rétablir le défaut** et confirmez : « Rétablir la version par défaut de … ? Vos modifications
seront supprimées. »

## Par où commencer

- **Standard** : c'est le template présélectionné quand rien d'autre ne l'est. Ajoutez-y ce que tous vos
  comptes rendus doivent contenir.
- **Entretien RH** : alignez ses parties sur votre grille d'entretien, dans le même ordre.
