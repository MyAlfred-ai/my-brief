## Où les voir

Dans le panneau **Actions détectées**, en haut de la colonne de droite, dès le démarrage de
l'enregistrement. Sur téléphone, le bouton **Actions** — dans la barre du bas pendant la réunion, en
bas à droite après — ouvre la liste ; il affiche le nombre d'actions et clignote à chaque nouvelle.

## Ce qui s'affiche

| Ce que vous voyez | Ce que ça veut dire |
|---|---|
| Un point qui pulse, « À l'écoute des actions… » | Aucune action pour l'instant |
| Une étincelle animée dans l'en-tête | Une analyse est en cours |
| Une carte qui glisse dans la liste | Une nouvelle action |
| Une carte dont le titre pulse et un champ qui s'éclaire | Une action précisée par la suite de la conversation |
| « Actions : 4 visibles · 1 masquées » | Le compte des actions affichées et masquées ; les masquées attendent sous **Actions masquées**, en bas de la liste |

Le bouton **Réduire les actions** replie le panneau, et **Afficher les actions** le rouvre ; myBrief s'en
souvient sur ce navigateur. Replié, il garde un **+** pour ajouter une action.

## Faire apparaître une action

L'IA repère ce qui se dit, pas ce qui se sous-entend. Pour qu'une tâche remonte :

- **dites-la comme une action** : « action pour Julie : préparer le devis » ;
- **nommez le porteur** : « Paul, tu t'en occupes ? » ;
- **donnez une échéance** : « avant vendredi », « le 15 ».

Le mot « action » est un mot déclencheur par défaut : une phrase qui le contient annonce une action.
D'autres mots peuvent être ajoutés — voir [Régler la détection](regler-la-detection.md).

## Ce qu'il faut savoir

- **Le délai** : une action apparaît en général dans les dix secondes qui suivent la phrase.
- **En pause**, rien n'est analysé.
- **La détection coupée**, rien n'apparaît tout seul, mais vous pouvez toujours ajouter des actions à la
  main. Le message « À l'écoute des actions… » s'affiche quand même.
- **Un audio importé** n'est analysé qu'une fois, en bloc.

Pour corriger ce qui est apparu : [Corriger et compléter les actions](corriger-et-completer-les-actions.md).
