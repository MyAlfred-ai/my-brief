## Avant de commencer

- **Vos destinataires**, réglés une fois pour toutes — ci-dessous. Sans liste, le mail part à vous seul.
- **De préférence, votre compte relié** : le mail part alors de votre propre boîte — voir
  [Relier son compte Google ou Microsoft](../connexion/relier-son-compte-google-ou-microsoft.md).

## Régler vos destinataires

1. Ouvrez **Ma configuration → Envoi d'email**.
2. Dans la carte **Envoyer par mail**, tapez une adresse puis Entrée, une virgule ou **Ajouter**. Une
   croix sur chaque adresse la retire. Le compteur indique la limite fixée par votre administrateur.
3. Facultatif : réglez l'**Objet du mail** — voir
   [Nommer les fichiers et l'objet du mail](nommer-les-fichiers-et-l-objet.md).
4. Cliquez **Enregistrer**.

« Vous êtes toujours en copie, quoi qu'il arrive » : votre adresse de connexion à myBrief n'a pas à
figurer dans la liste, et ne compte pas dans la limite.

## Envoyer

1. Ouvrez la réunion, onglet **Résumé** — ou **Transcription**.
2. Cliquez **Partager**, à droite des onglets, puis **Envoyer via le tag** — ou **Envoyer par mail**
   quand le tag de la réunion n'a pas de liste. Le sous-titre de l'entrée dit à qui le mail partira.

**Partager** affiche « Envoi… » le temps de l'envoi, puis un message confirme : « Document envoyé à … »,
avec les destinataires — les deux premiers, puis le nombre des autres (« +2 »).

Juste après le premier résumé d'une réunion, la fenêtre **Votre résumé est prêt** propose aussi
l'envoi, sans passer par **Partager** — voir
[Ranger et partager après le premier résumé](ranger-et-partager-apres-le-resume.md).

## Ce que reçoivent les destinataires

- **Le document dans le corps du mail**, entre une phrase d'introduction et une signature, dans la langue
  de l'interface.
- **Le document en pièce jointe** : le résumé en PDF, la transcription en fichier texte. Si le PDF ne
  peut pas être fabriqué, le mail part sans pièce jointe, et un message le dit.
- **L'objet** : « Résumé — Point client Dupont », ou votre format.

**L'objet et le nom du fichier reprennent le titre de la réunion**, aussi juste après la génération.
Ce titre est rédigé dans les secondes qui la suivent : un envoi fait plus tôt garde un objet générique.

## Deux façons de partir

Le badge de la carte le dit :

| Badge | Expéditeur | Destinataires |
|---|---|---|
| **via votre compte** | Votre boîte Gmail ou Outlook ; le mail est dans vos éléments envoyés | Toute la liste, vous en copie |
| **via le relais du serveur** | Une adresse d'envoi de myBrief | Vous seul — sauf si votre administrateur autorise le relais à écrire à d'autres, avec votre adresse en « répondre à » |

## Les tags changent les destinataires

Pour une réunion taguée dont le tag a sa liste, **c'est la liste du tag qui reçoit**, à la place de la
vôtre. Voir [Donner une destination à un tag](../tags/donner-une-destination-a-un-tag.md).

## Depuis la messagerie de votre téléphone

Pour relire le mail avant qu'il parte, ou l'adresser à quelqu'un de plus :

1. Ouvrez la réunion, onglet **Résumé** — ou **Transcription**.
2. Touchez **Partager**, puis **Rédiger dans ma messagerie**.

Votre application de mail s'ouvre sur un nouveau message :

- **les destinataires** sont déjà remplis : ceux du tag de la réunion, sinon votre liste par défaut —
  les mêmes que l'envoi automatique. Ajoutez-en, retirez-en ;
- **l'objet** : celui de l'envoi automatique — « Résumé — Point client Dupont », ou votre format ;
- **le corps** : le document en texte, titres et listes conservés. Pas de pièce jointe : pour le PDF,
  **Télécharger le PDF** puis joignez-le vous-même.

C'est votre messagerie qui envoie : le mail part de votre boîte, et myBrief n'en garde aucune trace. Le
choix existe **sur téléphone seulement**, et seulement si votre administrateur a ouvert l'envoi par
mail pour ce document.

Un texte trop long pour un mail — une transcription de plus d'une demi-heure environ — est coupé, et le
message « Trop long pour un mail : le texte a été coupé… » le signale. Pour l'envoyer en entier :
**Envoyer via le tag**, ou **Télécharger**.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| **Envoyer** n'est pas dans le menu **Partager** | L'action est fermée par votre administrateur, ou aucun moyen d'envoi n'existe : reliez votre compte. |
| « Document envoyé à vous seul : ce serveur n'est pas autorisé à écrire à des destinataires externes… » | Le mail est parti par le relais du serveur : reliez votre compte pour qu'il parte de votre boîte à toute la liste. |
| « Le document est trop volumineux pour être envoyé en pièce jointe… » | Téléchargez-le et envoyez-le vous-même. |
| « L'envoi par mail a échoué. Réessayez dans quelques instants. » | Réessayez. Si cela se répète, testez l'envoi — voir [Tester l'envoi et le dépôt](tester-l-envoi-et-le-depot.md). |
| « Adresses refusées : … » à l'enregistrement | L'adresse contient un espace, une virgule, des chevrons ou des guillemets : corrigez-la. |
| Le compte rendu d'un client est parti à votre équipe | La réunion n'avait pas le tag du client. |
| **Rédiger dans ma messagerie** n'ouvre rien | Aucune application de mail n'est installée ou configurée sur le téléphone. |
