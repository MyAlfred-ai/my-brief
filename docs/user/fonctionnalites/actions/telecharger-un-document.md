Télécharger ne demande ni compte relié ni réglage : le document s'enregistre sur votre appareil.

## Étapes

1. Ouvrez la réunion.
2. Cliquez **Partager**, à droite des onglets, puis :
   - **Télécharger le PDF**, sur l'onglet **Résumé** ;
   - **Télécharger la transcription**, sur l'onglet **Transcription**.

Le bouton affiche « Préparation… » le temps de fabriquer le PDF.

Dans l'application Android, la feuille de partage du système s'ouvre : enregistrez le fichier ou
envoyez-le à une application. Dans le navigateur, le fichier se télécharge.

Un second appui pendant la préparation est sans effet : un seul PDF sort.

## Ce que vous obtenez

| Document | Format | Contenu |
|---|---|---|
| **Le résumé** | PDF, nommé `mybrief_resume_2026-09-10.pdf` | Le titre « 📝 Résumé » et le template, la date, votre nom, puis le compte rendu affiché, retouches comprises. En pied de page, la mention de myBrief et le numéro de page |
| **La transcription** | Texte, nommé d'après la date et le titre de la réunion | Une ligne par phrase ; en visio, le nom du participant à chaque changement |

Le PDF contient du **vrai texte** : il se sélectionne, se copie et se recherche, les liens sont
cliquables, et les outils d'IA le lisent comme un document ordinaire. Il reste léger — une centaine de Ko
pour plusieurs pages — et aucune ligne n'est coupée entre deux pages. Il ne contient ni l'infographie,
ni la transcription, ni les notes.

## Les autres téléchargements

- **L'audio** : **Télécharger l'audio**, en bas de l'onglet **Transcription**, juste après
  l'enregistrement et dans le même navigateur — voir [Terminer une réunion](../pause-et-fin/terminer-une-reunion.md).
- **L'infographie** : **Télécharger l'infographie**, dans son affichage en grand — voir
  [Créer une infographie](../resumes/creer-une-infographie.md).

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| **Télécharger** n'est pas dans le menu **Partager** | Votre administrateur a fermé le téléchargement pour ce document. |
| « Erreur lors de la génération du PDF: … » | Réessayez ; si cela persiste, copiez le texte depuis l'onglet **Résumé**. |
| Le texte du PDF ne se sélectionne pas, et le fichier pèse plusieurs Mo | Le PDF a été préparé sans connexion : il est sorti en image de chaque page. Téléchargez-le à nouveau une fois connecté. |
