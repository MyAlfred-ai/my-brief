Pour les comptes qui se connectent par **Adresse email** et **Mot de passe**. Un compte Google ou
Microsoft n'en a pas besoin.

## Les règles

- **Dix caractères au moins.** Pas de règle de majuscules ni de chiffres : une phrase de passe fait
  très bien l'affaire.
- Pas de mot de passe trop courant — « motdepasse1 », « azerty123 »…
- Pas la partie de votre adresse qui précède « @ ».

## À la première connexion

Si votre administrateur vous a donné un mot de passe provisoire, la fenêtre **Choisissez votre mot de
passe** s'ouvre : « Votre compte utilise encore son mot de passe initial. Choisissez-en un nouveau pour
continuer. » Saisissez l'actuel, puis deux fois le nouveau, et **Enregistrer**. La fenêtre ne se ferme
pas avant.

## Changer de mot de passe

1. Cliquez votre nom, en bas de la colonne de gauche — sur téléphone, votre avatar, en haut à
   droite —, puis **Changer de mot de passe**.
2. Saisissez le **Mot de passe actuel**, le **Nouveau mot de passe**, puis **Confirmer le nouveau mot de
   passe**.
3. Cliquez **Enregistrer**.

« Mot de passe modifié. Vos autres appareils ont été déconnectés. » : vous restez connecté ici.

L'entrée n'apparaît pas si vous vous êtes connecté par Google, Microsoft ou le SSO, ni dans
l'application mobile.

## Mot de passe oublié

1. Sur la page de connexion, cliquez **Mot de passe oublié ?**.
2. Saisissez votre adresse, puis **Envoyer le lien**.
3. Ouvrez le mail reçu et cliquez le lien. Il sert une fois, et expire au bout de trente minutes.
4. **Choisissez un nouveau mot de passe**, puis **Enregistrer le mot de passe**.
5. « Mot de passe enregistré. Vous pouvez vous connecter. »

Le message est le même que l'adresse ait un compte ou non : c'est voulu. Toutes vos sessions sont
fermées.

**Pas de lien « Mot de passe oublié ? »** sur la page de connexion : votre installation n'envoie pas de
mails. Demandez à votre administrateur de réinitialiser votre mot de passe.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| « Mot de passe actuel incorrect. » | Ressaisissez-le ; au besoin, passez par **Mot de passe oublié ?**. |
| « Ce mot de passe est trop courant. » | Choisissez-en un moins prévisible. |
| « Le mot de passe ne doit pas contenir votre adresse email. » | Retirez-en votre identifiant. |
| « Ce lien a expiré ou a déjà été utilisé. Demandez-en un nouveau. » | Redemandez un lien. |
| « La réinitialisation par email n'est pas configurée sur ce serveur. » | Demandez à votre administrateur de réinitialiser votre mot de passe. |
| Le lien ouvre myBrief sans le formulaire | Vous êtes déjà connecté sur ce navigateur : déconnectez-vous, puis rouvrez le lien. |
| Aucun mail reçu | Vérifiez les indésirables. Trois demandes par heure au plus pour une même adresse. |
