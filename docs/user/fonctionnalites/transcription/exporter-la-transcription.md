La transcription peut quitter myBrief sous forme de fichier texte : par mail, dans votre Drive ou votre
OneDrive, ou sur votre appareil.

## Étapes

1. Ouvrez la réunion, onglet **Transcription**. Les boutons n'apparaissent pas pendant l'enregistrement.
2. Cliquez **Partager**, à droite des onglets, puis l'action voulue. Sur téléphone, le menu propose aussi
   **Rédiger dans ma messagerie**, qui ouvre la transcription dans votre application de mail, prête à
   relire.

| Entrée du menu | Effet |
|---|---|
| **Envoyer par mail** — ou **Envoyer via le tag** | Le texte part dans le corps du mail, avec un fichier .txt joint, à vos destinataires |
| **Entreposer dans Google Drive** (ou **OneDrive**) — ou **Entreposer via le tag** | Le fichier .txt est déposé dans votre dossier de dépôt |
| **Télécharger la transcription** | Le fichier .txt s'enregistre sur votre appareil ; dans l'application Android, la feuille de partage s'ouvre |

Les destinataires, le dossier et le nom du fichier se règlent une fois pour toutes : voir
[Les actions après réunion](../actions/index.md).

## Le fichier

- Du texte simple, une ligne par phrase, sans les heures.
- En visio, une ligne **[Nom]** ou **[Visio]** marque chaque changement de participant.
- Son nom : la date et le titre de la réunion — `2026-09-10-point-client-acme.txt` —, sauf si vous avez
  réglé un autre format de nom.

## Ce qu'il faut savoir

- **Votre administrateur décide** quelles actions existent : une entrée absente du menu est une action
  fermée sur votre installation.
- **L'audio** n'est pas dans ce menu : **Télécharger l'audio**, en bas de l'onglet, n'existe que
  juste après l'enregistrement, dans le navigateur qui a enregistré — voir
  [Terminer une réunion](../pause-et-fin/terminer-une-reunion.md).
