## Poser un tag

Trois endroits, un même menu :

| Quand | Où |
|---|---|
| **Pendant l'enregistrement** | Le bouton de tag, dans la barre du haut, à côté de « Enregistrement en cours… » |
| **Sur une réunion ouverte** | Le bouton de tag, à droite des onglets **Transcription** et **Résumé** |
| **Dans l'historique** | Clic droit sur la réunion — ou le bouton **⋯** sur écran tactile —, puis **Tag** |

Dans le menu, cliquez le tag voulu ; une coche marque le tag actuel. **Aucun tag** retire le rangement.
**Gérer les tags…** ouvre **Mes tags** pour en créer un.

**Rangez pendant la réunion.** Le tag décide des destinataires et du dossier au moment où vous envoyez
ou déposez le compte rendu : posé à l'avance, il n'y a plus à y penser.

## Résultat

La pastille du tag — sa couleur, son motif s'il en a un, sa forme — précède le titre de la réunion
dans l'historique ; son nom s'affiche au survol.

## Filtrer l'historique

1. Cliquez **Filtrer par tag**, sous le champ de recherche. Le bouton n'apparaît qu'une fois votre
   premier tag créé.
2. Choisissez un tag — ou **Sans tag**, pour les réunions pas encore rangées. Chaque ligne indique le
   nombre de réunions.
3. Pour tout revoir : **Tous**, ou **Tout afficher** dans le bandeau « 3 réunions masquées par le
   filtre ». Recliquer le tag actif fait de même.

Le filtre se combine avec la recherche. myBrief s'en souvient sur ce navigateur ; un autre appareil
garde le sien.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| Le bouton de tag n'apparaît pas sur une réunion ouverte | La réunion n'est pas encore connue du serveur — démarrée hors ligne, par exemple : générez son résumé, puis rangez-la. |
| « Aucune réunion avec ce tag » | Le filtre est actif : cliquez **Tous**. |
| Le tag n'a pas été posé | La pastille est revenue à l'état précédent : le serveur n'a pas répondu. Réessayez. |
