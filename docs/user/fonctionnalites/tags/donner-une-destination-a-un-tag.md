Un tag peut porter **ses destinataires** — pour **Envoyer par mail** — et **son dossier** — pour
**Entreposer**. Pour une réunion taguée, ils remplacent vos réglages habituels.

## Avant de commencer

- Pour le dossier : un compte Google ou Microsoft relié, avec l'accès aux fichiers — voir
  [Relier son compte Google ou Microsoft](../connexion/relier-son-compte-google-ou-microsoft.md).
- Pour les destinataires : rien à relier.
- Votre administrateur doit avoir ouvert l'envoi par mail et le dépôt. Fermés, les choix sont grisés et
  une note le dit ; vos réglages restent enregistrés et reprendront s'il les rouvre.

## La fiche du tag

Dans **Ma configuration → Mes tags**, choisissez le tag dans la liste. Sa fiche pose deux questions,
chacune avec deux réponses : la règle **commune** à tous vos tags, ou une règle **à lui**. La réponse
retenue prend la couleur du tag. Chaque choix s'enregistre aussitôt : il n'y a pas de bouton
**Enregistrer**.

## Où ranger ses comptes rendus ?

**Avec les autres comptes rendus.** Le tag suit la règle commune. La fiche dit où cela mène :

- *Directement dans votre dossier principal* — par exemple *Comptes-rendus* ;
- *Dans un dossier à son nom, créé au premier dépôt* — *Comptes-rendus › Client Dupont* —, si l'option
  **Un sous-dossier par tag** est activée.

**Dans un dossier que je choisis.** La fenêtre de choix de dossier s'ouvre : choisissez le dossier — y
compris dans un Drive partagé ou une bibliothèque SharePoint —, puis **Choisir ce dossier**. La fiche
affiche le dossier et sa bibliothèque, précédés de son logo : Google Drive, OneDrive ou SharePoint.
**Changer de dossier** en choisit un autre. Fermer la fenêtre sans choisir ne change rien.

Revenir à **Avec les autres comptes rendus** retire le dossier du tag. Le dossier d'un tag se choisit
dans la fenêtre : il ne se tape pas.

## À qui envoyer ses comptes rendus ?

**Aux destinataires habituels.** La fiche rappelle qui c'est : « Aujourd'hui : vous seul. », « vous + 2
adresses »…

**À des personnes précises.** La fenêtre **Destinataires du tag** s'ouvre : ajoutez les adresses —
Entrée, virgule ou **Ajouter** après chacune —, puis **Valider**. La fiche les affiche ; **Modifier la
liste…** les change. Ces adresses **remplacent** vos destinataires habituels pour les réunions de ce
tag ; vous restez en copie.

Revenir à **Aux destinataires habituels** retire la liste du tag ; une liste validée vide aussi.

## Les réglages communs

L'entrée **Réglages communs**, en bas de la liste des tags, montre ce que « les autres comptes rendus »
et « les destinataires habituels » désignent :

- le **Dossier principal**, avec le logo de sa bibliothèque — **Modifier dans Entreposer** ;
- l'interrupteur **Un sous-dossier par tag** : chaque tag sans dossier à lui range alors ses comptes
  rendus dans *dossier principal / nom du tag*, créé au premier dépôt ;
- les **Destinataires habituels** — **Modifier dans Envoi d'email**.

Le dossier principal et les destinataires habituels servent aussi aux réunions sans tag : ils se
règlent sur leur page.

## Résultat

Pour une réunion rangée dans ce tag, **Envoyer par mail** et **Entreposer** suivent ses règles. Le
message de dépôt nomme le dossier et la bibliothèque utilisés : « Document déposé dans « Clients/Dupont »
(Mon Drive). »

## Où d'autre régler la même chose

**Ma configuration → Envoi d'email → Destinataires par tag** et **Ma configuration → Entreposer →
Destinations par tag** donnent les mêmes réglages, tag par tag, avec un bouton **Enregistrer** pour la
page. Dans **Mes tags**, chaque geste s'enregistre tout seul.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| Les choix du rangement sont grisés | Le dépôt est fermé par votre administrateur, ou votre compte n'est pas relié avec l'accès aux fichiers : la note sous les choix dit lequel. |
| « Reliez votre compte Google ou Microsoft (Ma configuration → Connexion) pour choisir des dossiers. » | Reliez votre compte — voir [Relier son compte Google ou Microsoft](../connexion/relier-son-compte-google-ou-microsoft.md). |
| « Impossible d'enregistrer la destination. Réessayez. » | Le serveur n'a pas répondu : la fiche est restée sur l'ancien choix. Réessayez. |
| Le compte rendu d'un client est parti à vos destinataires habituels | La réunion n'avait pas de tag, ou le tag est réglé sur **Aux destinataires habituels**. Vérifiez la fiche du tag. |
